Die Registrierungsrevision beschreibt die lokale Einrichtung und wird unabhängig von der Erweiterungsversion gezählt. Eine frühere Bestätigung beweist nicht, dass die aktuelle Verbindung funktioniert.

Lokalen MCP-Server installieren und registrieren

Das Registrierungsskript installiert oder aktualisiert im gewählten Verzeichnis einen lokalen MCP-Server und Native-Messaging-Helfer auf Basis von Node.js. Anschließend registriert es den Helfer bei Firefox und richtet passende Einträge bei unterstützten KI-Clients ein.

Serverdateien und npm-Abhängigkeiten benötigen ungefähr 22 MB. Falls unter Windows zusätzlich Node.js heruntergeladen werden muss, benötigt dessen Laufzeit weiteren Speicherplatz. Der Server läuft außerhalb von Firefox; das Add-on stellt die Browserfunktionen und Freigaben bereit.

Wähle das Betriebssystem, auf dem Firefox und der lokale Server laufen.

Das Skript schlägt bei einer vorhandenen Registrierung deren bisherigen Installationsordner vor. Das kann auch ein Entwicklungsverzeichnis sein. Du kannst einen anderen absoluten Pfad eingeben; eine abweichende bestehende Registrierung wird nicht still überschrieben. Im bestätigten Zielordner werden die enthaltenen Server- und Einrichtungsdateien aktualisiert und können ersetzt werden.

Öffne ein Terminal im Ordner der gespeicherten Skripte.

Ein Doppelklick auf eine .ps1-Datei öffnet häufig nur den Editor. Die Ausführungsrichtlinie wird mit diesen Befehlen nur für den gestarteten Skriptprozess gesetzt.

  1. Speichere das passende Registrierungsskript.
  2. Führe die gespeicherte Datei selbst aus und folge ihren Angaben. Wähle für das Aktualisieren einer vorhandenen Projektinstallation deren Installationsordner ausdrücklich aus. Eine abweichende bestehende Registrierung wird nicht still überschrieben.
  3. Klicke nach Abschluss auf „Erneut prüfen“. Erst die Rückmeldung des Native Hosts bestätigt den ausgeführten Stand.

Der Download kommt direkt aus dem Erweiterungspaket und funktioniert ohne Internetverbindung. Die Skripte enthalten den lokalen Server. Während ihrer Ausführung können Node und npm-Abhängigkeiten aus dem Internet geladen werden.

Unregister entfernt die Firefox-Native-Host-Registrierung, den zugehörigen Registrierungsbeleg und nach Möglichkeit die passenden verwalteten KI-Client-Einträge. Der Installationsordner wird nicht gelöscht: Serverdateien, node_modules, eine lokal installierte Node.js-Laufzeit, Quellcode und Einstellungen bleiben erhalten – auch bei einer reinen Laufzeitinstallation. Das Add-on selbst wird nicht deinstalliert. Bestehende Verbindungen danach neu laden. Auch dieses Skript wird erst nach dem Speichern manuell ausgeführt.
