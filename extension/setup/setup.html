Die Registrierungsrevision beschreibt die lokale Einrichtung und wird unabhängig von der Erweiterungsversion gezählt. Eine frühere Bestätigung beweist nicht, dass die aktuelle Verbindung funktioniert.

Registrierungsskripte

Wähle das Betriebssystem, auf dem Firefox und der lokale Server laufen.

Registrierungsskript speichernDeregistrierungsskript speichern

Öffne ein Terminal im Ordner der gespeicherten Skripte.

Ein Doppelklick auf eine .ps1-Datei öffnet häufig nur den Editor. Die Ausführungsrichtlinie wird mit diesen Befehlen nur für den gestarteten Skriptprozess gesetzt.

  1. Speichere das passende Registrierungsskript.
  2. Führe die gespeicherte Datei selbst aus und folge ihren Angaben. Wähle für das Aktualisieren einer vorhandenen Projektinstallation deren Installationsordner ausdrücklich aus. Eine abweichende bestehende Registrierung wird nicht still überschrieben.
  3. Klicke nach Abschluss auf „Erneut prüfen“. Erst die Rückmeldung des Native Hosts bestätigt den ausgeführten Stand.

Der Download kommt direkt aus dem Erweiterungspaket und funktioniert ohne Internetverbindung. Die Skripte enthalten den lokalen Server. Während ihrer Ausführung können Node und npm-Abhängigkeiten aus dem Internet geladen werden.

Das Deregistrierungsskript entfernt die lokale Registrierung. Es wird ebenfalls erst nach dem Speichern manuell ausgeführt.
